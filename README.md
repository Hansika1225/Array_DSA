# 📌 Array DSA Practice

This repository contains **Data Structures and Algorithms (DSA) practice questions based on Arrays**, implemented in **C++**.  
It is intended for strengthening problem-solving skills and preparing for **coding interviews, placements, and competitive programming**.

---

## 🚀 Topics Covered

- Basics of Arrays
- Traversing an Array
- Finding Maximum & Minimum
- Reverse an Array (Two-Pointer Technique)
- Remove Duplicates from Sorted Array
- Second Largest Element
- Frequency of Elements
- Left & Right Rotation of Array
- Linear Search
- Array Manipulation Problems
- Two Sum Problem
- Prefix Sum
- Maximum Subarray Problems
- Sliding Window
- Divide And Conquer

---

## 🧠 Approach

- Focus on **optimized solutions**
- Uses techniques like:
  - Two-pointer approach
  - In-place modification
  - Iterative logic
- Each program is written with **clear logic** and **readable code**
